# Асинхронный парсер PEP

Проект представляет собой асинхронный парсер документов PEP, реализованный с использованием Scrapy.

Парсер получает данные с сайта:

https://peps.python.org/

и сохраняет результаты работы в CSV-файлы.

## Возможности проекта

Парсер собирает информацию обо всех документах PEP:

- номер PEP;
- название PEP;
- текущий статус документа.

После завершения работы создаются два CSV-файла:

1. Файл со списком всех найденных PEP:

`pep_ДатаВремя.csv`

Файл содержит следующие столбцы:

- Номер
- Название
- Статус

2. Файл со статистикой по статусам:

`status_summary_ДатаВремя.csv`

Он содержит количество документов для каждого статуса PEP.

Последняя строка содержит `Total` и общее количество найденных документов.

Все результаты сохраняются в директорию:

`results/`

## Установка

Клонируй репозитирий: 

`git clone https://github.com/klimatroniks/scrapy_parser_pep/`

Перейди в директорию проекта:

`cd scrapy_parser_pep`

Создай виртуальное окружение:

`python -m venv venv` 

Активируй виртуальное окружение:

- Для Windows
`venv\Scripts\activate`

- Для Mac   `source venv/bin/activate`

Установи зависимости:

`pip install -r requirements.txt`

Запускай парсер:

`scrapy crawl pep`

После завершения работы результаты будут находиться в директории:

`results/`

Пример файлов:

`pep_2026-09-24T18-30-00.csv`  
`status_summary_2026-09-24_18-30-00.csv`

## Запуск тестов

## Как работает парсер

Парсер начинает работу со страницы:

https://peps.python.org/

Метод `parse()` получает ссылки на страницы отдельных документов PEP и передаёт их в метод `parse_pep()`.

Метод `parse_pep()` получает со страницы документа:

- номер PEP;
- название PEP;
- статус документа.

Полученные данные сохраняются в объект `PepParseItem`.

Список всех PEP сохраняется в CSV-файл с помощью механизма Scrapy Feeds.

Pipeline подсчитывает количество документов для каждого статуса PEP и после завершения работы парсера создаёт отдельный CSV-файл со сводной статистикой.

В последней строке файла со статистикой выводится `Total` и общее количество найденных документов.
